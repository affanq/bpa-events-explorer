Description & Eligibility
Contestants will demonstrate ability in hardware and system configuration, system operation and maintenance,
security, scripting, troubleshooting and diagnostics within the Linux Operating System. Any secondary or
postsecondary division contestant may enter this objective event.

Contest Competencies
1.
Utilize Linux command line utilities and configure shell environments to manage files, processes,
and automate system tasks for optimized workflows
2. Configure and manage Linux storage devices, file systems, networking, and printing services to
support organizational performance and resource availability
3. Configure, monitor, and manage Linux system access controls, including permissions, ACLs, and
authentication mechanisms, to enforce organizational security policies
4. Install, configure, and update Linux software packages using distribution -specific package
management tools to maintain secure and functional systems
5. Perform Linux operating system installation, configure system bootloaders such as GRUB, and
manage boot processes to ensure proper system initialization and recovery capabilities
6. Create, modify, and manage files using Linux text editors and employ search and manipulation
commands to support effective system administration
7. Configure and administer Linux firewalls, network interfaces, and essential network services to
support secure and reliable connectivity
