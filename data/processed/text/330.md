330 C# Programming

Description & Eligibility
Contestants will demonstrate practical knowledge of C# development, including core syntax, programming
logic, application design, and use of objects, data access, and IDE tools within a Windows environment.
This event will be graded on the Windows operatin g system; therefore, Unix/Linux should not be used.
Any secondary or postsecondary division contestant may enter this application event.

Contestant Must Supply
• Published and/or unpublished non -electronic written reference materials
• Computer or laptop/notebook (USB -Type A or adapter required); a full -size keyboard may be
used (no printer is needed) and supporting equipment (extension cords, etc.)
• Contestant must use one of these IDEs: Visual Studio 2022, Visual Studio Code, VSCode

• Only pre -written code that is hard copied is allowed

Contest Competencies
1.
Apply object -oriented programming principles and structured design techniques, along with
efficient algorithms, to design, implement, and maintain scalable, reusable software solutions
2. Demonstrate foundational understanding of computer science concepts and proficiency in at least
one modern programming language
3. Create and interpret UML diagrams to model software architecture and communicate design
decisions within development teams
4. Use Entity Framework Core to design, query, and manage relational databases through
object-relational mapping (ORM) techniques that support scalable application development
5. Write expressive, efficient data queries using LINQ and lambda expressions to manipulate
collections, interact with databases, and simplify complex logic within .NET applications
6. Demonstrate proficiency in developing C# Windows Desktop Programming, emphasizing Windows
Forms, WPF, OOP, collections, file access, debugging, and desktop UI design
7. Develop and maintain applications using updated .NET 6+ platform features, including
performance enhancements, minimal APIs, modern runtime capabilities, and streamlined
deployment workflows
