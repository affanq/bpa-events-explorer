Contest Competencies
1.
Design and implement normalized relational database schemas by applying keys, constraints, and
normalization techniques (up to 3NF) to ensure data integrity and scalability
2. Select appropriate data types and design indexes to optimize storage, accuracy, and query
performance in medium- to large-scale database systems
3. Design and manage schemas and use DDL and DML commands to create, modify, and
manipulate database structures and data securely and efficiently
4. Write advanced SQL queries using WHERE clauses, joins, set operations (UNION, INTERSECT),
and aggregate functions to retrieve, combine, and analyze data for business insights
5. Create and manage views, implement transactions, and design backup and recovery strategies to
ensure secure, consistent, and resilient database operations
6. Develop and manage stored procedures to automate database operations, enforce business
logic, and improve performance
7. Distinguish and evaluate relational and NoSQL database architectures for diverse business
applications
8. Configure and manage traditional on -premises database servers to support scalable, secure, and
highly available database environments
9. Demonstrate awareness of Object -Relational Mapping (ORM) technologies —including Hibernate
and Entity Framework Core —to understand how applications interact with relational databases
through abstraction layers
10. Apply advanced query optimization strategies beyond basic indexing, such as execution plan
analysis, query refactoring, partitioning, and memory/IO tuning to improve performance in
complex workloads
11. Implement security best practices for stored procedures, including input validation,
least-privilege execution, schema separation, and protection against SQL injection and privilege
escalation
