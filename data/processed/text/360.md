Description & Eligibility
Contestants will demonstrate knowledge of fundamental web design coding and syntax to include CSS3
and HTML5 standards. Any secondary or postsecondary division contestant may enter this application
event.

Contestant Must Supply
• Published and/or unpublished non -electronic written reference materials
• Sharpened pencils, pens
• (Optional) Cordless calculator: Electronic devices will be monitored according to ACT standards.
See NLC Calculator Guidelines. Contestants who violate this rule will be
disqualified.

Contest Competencies
1.
Develop and maintain web pages using semantic HTML5 and CSS3 standards, applying responsive
typography, layout, and formatting techniques to ensure accessibility, SEO, and consistent
branding across devices
2. Implement Web Content Accessibility Guidelines and ensure cross
-browser compatibility using
progressive enhancement and testing tools to deliver inclusive and consistent user experiences
3. Create accessible and responsive tables, integrate optimized images, and implement secure, user -
friendly hyperlinks using HTML5 and CSS3 best practices to enhance performance, usability, and
SEO
