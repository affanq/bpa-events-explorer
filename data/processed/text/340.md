340 Java Programming

Description & Eligibility
Contestants will demonstrate knowledge and application of Java programming, including structured
design, algorithm development, and object-oriented methodologies. This event will be graded on the
Windows operating system; therefore, Unix/Linux should not be used. Any secondary or postsecondary
division contestant may enter this application event.

Contestant Must Supply
• Published and/or unpublished non -electronic written reference materials
• Computer or laptop/notebook (USB -Type A or adapter required); a full -size keyboard may be
used (no printer is needed) and supporting equipment (extension cords, etc.)
• Contestant must use one of these IDEs: IntelliJ, Eclipse, NetBeans, BlueJ,
VSCode
• Only pre -written code that is hard copied is allowed

Contest Competencies
1.
Demonstrate proficiency in Java programming and apply algorithmic thinking and language syntax,
core concepts, and modern practices to implement effective Java solutions
2. Develop modular, maintainable programs using foundational object-oriented principles
3. Use Java file I/O to read, write, and manage data in applications
4. Apply structured and object -oriented design techniques and implement effective error handling
strategies to create scalable, maintainable, and resilient Java applications
5. Create and interpret UML diagrams to model software architecture and communicate design
decisions in Java projects
6. Utilize the Java Collections Framework to efficiently store, manage, and manipulate data using
lists, sets, maps, iterators, or collection algorithms
7. Apply standard Java libraries and modern language features to write clean, maintainable code
