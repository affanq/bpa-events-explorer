Description & Eligibility
Contestants will demonstrate foundational and advanced knowledge of modern computer networking,
including architectures, protocols, hardware, connectivity, and security. This event evaluates real -world
concepts used in today’s enterprise environments. Any secondary or postsecondary division contestant may
enter this objective event.

Contest Competencies
1.
Design, configure, and troubleshoot computer networks using OSI/TCP -IP models, subnetting, and
IPv4/IPv6 addressing to ensure scalable and secure connectivity
2. Install, configure, and troubleshoot computer hardware components to ensure reliable
performance and minimize downtime in networked environments
3. Configure and manage core network services including DNS, DHCP, etc. to enable efficient name
resolution, addressing, and resource discovery
4. Deploy and manage cloud, virtualization, and secure remote -access technologies to support
scalable and hybrid network infrastructures
5. Administer directory services and operating systems to ensure secure authentication, centralized
management, and efficient enterprise operations
6. Identify key features of Wi -Fi 6/6E/7, explain how they improve network efficiency and
performance, and describe appropriate use cases for modern wireless deployments
