315 Network Administration Using Cisco®

Description & Eligibility
Contestants will demonstrate foundational knowledge of network administration within a Cisco®
environment. This event focuses on essential skills in configuring, managing, and securing network devices
and architectures. Any secondary or postsecondary divis ion contestant may enter this objective event.

Contest Competencies
1.
Design, configure, secure, and optimize routing, switching, VLANs, and First Hop Redundancy Protocols
(FHRP) to ensure efficient, segmented, and highly available enterprise networks
2. Design and implement scalable LAN/WAN topologies using advanced routing, switching, and security
protocols to support resilient and secure network infrastructures
3. Configure and manage NAT, IPv4/IPv6 addressing, and access control lists (ACLs) to secure and
control network traffic in modern environments
4. Implement network management solutions to monitor, analyze, and maintain network health,
performance, and security
5. Explain the fundamentals of Software -Defined Networking (SDN) and how centralized control,
programmability, and abstraction improve network flexibility, automation, and security
6. Use network automation tools to streamline configuration, reduce errors, and improve efficiency in
managing network devices and services
7. Configure wireless LAN controllers (WLCs) to manage access points, apply wireless policies, and
ensure secure, scalable, and high-performance wireless network operations
8. Plan and deploy wireless access points by analyzing coverage needs, interference, capacity
requirements, and best-practice placement to support reliable and efficient wireless connectivity
