310 Server Administration Using Microsoft®

Description & Eligibility

Contestants will demonstrate core knowledge of server administration within a Windows® network
environment. This event focuses on fundamental network management, system configuration, and
maintenance tasks performed by IT administrators. Any secondary or p ostsecondary division contestant
may enter this objective event.

Contestant Must Supply
• Published and/or unpublished non -electronic written reference materials, including hands -on tasks.
• (Optional) Cordless calculator: Electronic devices will be monitored according to ACT standards.
See NLC Calculator Guidelines .  Contestants who violate this rule will be disqualified.

Equipment/Supplies Provided
• Computer and software

Contest Notes
• Method of evaluation: objective
• AI Policy Level 1 No AI Allowed
• Previous Business Professionals of America tests and/or sample tests (handwritten, photocopied
or keyed) may not be taken into the testing area. Violation of this rule will result in disqualification.
• The top 10 contestants at Nationals will advance to a final round that includes a hands -on
component. Scores from the preliminary round and the objective test will not carry over to the
finals. Reference materials may be used during the application portion of the final round.
• Length of event
o Preliminaries - No more than sixty (60) minutes for objective test
o Preliminaries (Nationals only) - No more than sixty (60) minutes for objective test , and no
more than sixty (60) minutes for performance component
o Finals (Nationals only) - No more than sixty (60) minutes for performance component
• Entries vary by state

Contest Competencies
1.
Monitor, manage, and troubleshoot access to files, folders, and shared resources to ensure data
security and user productivity
2.
Install, configure, and troubleshoot Windows® operating systems, hardware devices, and drivers to
ensure compatibility, stability, and reliable deployment
3. Monitor, analyze, and optimize system performance and implement backup and recovery solutions to
ensure reliability and minimize downtime
4. Implement and manage data encryption, auditing, and security policies in Windows® environments to
ensure compliance and protect organizational assets
5. Configure and manage Azure AD / Entra ID to support secure user authentication, access management,
and identity protection in cloud -connected environments
6. Implement and troubleshoot hybrid identity solutions and Single Sign -On (SSO) to provide seamless,
secure access across on -premises and cloud resources
7.
Use Microsoft Intune to enroll, configure, secure, and manage devices through cloud -based policies,
ensuring consistent settings and compliance across the organization
8. Configure and maintain virtualization clusters to provide high availability, load balancing, and resilient
performance in virtualized environments
9. Deploy and manage Active Directory Domain Services and Group Policy, and configure and
troubleshoot core network services including DNS and DHCP to support a Windows Server domain
environment
10. Install and configure Windows Server roles and features; administer systems using PowerShell;
implement file, storage, backup, and recovery services; apply patch and update management; and
deploy Hyper -V and failover clustering for high availability
