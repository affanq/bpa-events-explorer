Description & Eligibility
Contestants will evaluate knowledge of working with structured designs, algorithms, and OOP
methodology using standard libraries in the Python programming language. This event will be graded on
the Windows operating system; therefore, Unix/Linux should not be used. Any secondary or
postsecondary division contestant may enter this application event.

Contestant Must Supply
• Published and/or unpublished non -electronic written reference materials
• Computer or laptop/notebook (USB -Type A or adapter required); a full -size keyboard may be
used (no printer is needed) and supporting equipment (extension cords, etc.)
• Contestant must use one of these IDEs: IDLE, Visual Studio, Visual Studio Code, PyCharm,
VSCode
• Only pre -written code that is hard copied is allowed

Contest Competencies
1.
Demonstrate proficiency in Python programming and apply algorithmic thinking, language syntax,
core concepts, and modern practices to implement effective Python solutions
2. Develop modular, maintainable programs using foundational object-oriented principles in Python
3. Use Python file I/O to read, write, and manage data in applications
4. Apply structured and object -oriented design techniques and implement effective error -handling
strategies to create scalable, maintainable, and resilient Python applications
5. Create and interpret UML diagrams to model software architecture and communicate design
decisions in Python projects
6. Utilize Python’s built-in collections and data structures —including lists, sets, dictionaries, tuples,
iterators, or related utilities—to efficiently store, manage, and manipulate data
7. Apply standard Python libraries and modern language features to write clean, readable, and
maintainable code
